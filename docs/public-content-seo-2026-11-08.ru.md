# Публичный контент, niqqud и органический поиск

Дата: 08.11.2026. Прямое указание владельца в HR-17 после проверки главной страницы: убрать niqqud из отображаемого сайта и предотвратить повторение, удалить FAQ об AI, объяснить пустые компании, предложить улучшение footer и три FAQ, исследовать ключевые фразы Израиля.

## Подтверждённые данные и изменения

Read-only anonymous API через публичный publishable client: 37 строк public_job_catalog, все импортированные; 0 опубликованных company_profiles; 0 компаний, удовлетворяющих связи profile.organization_id с открытыми вакансиями; 1 заголовок с niqqud. Это снимок на дату проверки, а не постоянные показатели. Название источника импортированной вакансии не делает компанию зарегистрированным клиентом платформы.

Пустой блок «Companies hiring now» на главной не выводится до появления опубликованных профилей с открытыми связанными вакансиями. Ошибки загрузки и отсутствие данных не заменяются фиктивными компаниями. Каталог компаний и его честное пустое состояние сохраняются.

FAQ «Are AI tools active?» удалён в he/en. Остальные ответы не изменены. Три новых вопроса и footer ниже — предложения, не уже опубликованные функции.

`lib/hebrew-text.mjs` удаляет Hebrew cantillation/vowel marks, включая dagesh и shin/sin dots; сохраняет буквы, maqaf, geresh/gershayim, paseq и sof pasuq, латинские диакритики и другие языки. Общий клиент Supabase очищает текстовые значения в успешных JSON REST-ответах (включая RPC, которые читают экраны кабинетов). Сохраняются status/Content-Range; Content-Length/Encoding пересозданного тела удаляются. Тела запросов, ошибки, Auth и Storage-файлы не изменяются; ID, URL, object_path, email/phone/token и другие машинные поля исключены. Рабочая БД не переписывается. Auth fallback names очищаются перед показом. `localizeJob`, browser title, metadata и share text также очищаются. Исходные файлы/PDF/картинки, содержимое которых отображается внутри отдельного viewer, не редактируются; маркировка не удаляется из секретов/ссылок/идентификаторов. Новый статический niqqud в app/lib запрещён regression test. Новые интеграции должны проходить через этот текстовый слой.

## SEO: выполненный фундамент

- Сохранены утверждённые titles Find Jobs и חיפוש משרות, default English, сохранённый выбор he/en.
- Естественные фразы «חיפוש עבודה בישראל», «משרות פנויות», «דרושים» / «find jobs in Israel», «open positions» внесены в hero/search heading и локализованные descriptions. Перечень ключей не прячется и не дублируется искусственно.
- Исправлен старый fallback canonical/sharing origin headhunter-preview.vercel.app на https://www.hr-ai.tech; явно заданный корректный HTTPS origin для отдельного deployment поддерживается.
- Только VERCEL_ENV=production разрешает индексирование главной и подтверждённой опубликованной вакансии. Default root metadata и внутренние маршруты остаются noindex. Глобальный HTTP noindex сохранён, за исключением `/` в Production; для private/auth/query state более строгий metadata noindex имеет приоритет над HTTP index.
- Query view/invite/company/code/token и неизвестное состояние не индексируются. Несуществующие/недоступные вакансии noindex. Preview/development сохраняют запрет индексации.
- robots.txt в Production разрешает публичную часть и исключает /api/, /review, /client-portal; указывает sitemap.xml. В Preview запрещает всё. Sitemap на данном этапе включает только главную без фиктивных lastModified и количества вакансий.

Это не приёмка полного SEO: Google ещё должен просканировать сайт. Search Console не подключался, sitemap туда не отправлялся, объёмы запросов/позиции/трафик не измерялись. Отдельные URLs he/en и hreflang, региональные посадочные, полный серверный контент вакансий, sitemap вакансий и JobPosting требуют следующего этапа. Не добавлены несуществующие даты публикации, зарплаты, работодатели или directApply. Главная без cookie English — это сохраняет требование владельца; для целевого поиска на иврите нужны самостоятельные Hebrew URLs.

## Срез рынка Израиля и карта фраз

Исследованы текущие первичные публичные страницы [JobMaster](https://www.jobmaster.co.il/), [Drushim](https://www.drushim.co.il/), страница [AllJobs](https://www.alljobs.co.il/Home2.aspx) в поисковой выдаче (прямое открытие вернуло 403), а также конкретные результаты для student nursing/Netanya. Конкуренты строят навигацию по профессии, географии, занятости и опыту. Эти наблюдения подтверждают структуру намерения, но не доказывают популярность, сложность или объём запросов. Выдача — выборка, не позиционный мониторинг Google Israel.

| Приоритет | Фразы | Целевое содержимое |
|---|---|---|
| Первый — реальные вакансии | משרות לסטודנטים לסיעוד בנתניה; דרושים פיזיותרפיסטים בנתניה; דרושים מרפאים בעיסוק בשרון; דרושים עובדים סוציאליים בשרון | Конкретная опубликованная вакансия, реальная должность + место, требования и занятость |
| Первый — локальное намерение | דרושים בנתניה; עבודה בנתניה; דרושים בחדרה; דרושים בשרון | Полезные региональные каталоги, только при наличии подходящих вакансий; пока это план посадочных |
| Затем — категория/занятость | דרושים רפואה ובריאות; משרות בסיעוד; משרה חלקית בנתניה | Подтверждённые фильтры/каталоги без выдуманного опыта или условий |
| Долгосрочно — общие | חיפוש עבודה; דרושים; משרות פנויות; עבודה בישראל; חיפוש משרות | Главная и общий каталог, конкуренция с крупными порталами; место #1 не обещается |
| English | jobs in Israel; find jobs in Israel; jobs in Netanya; jobs in Hadera | Английские страницы и фактическое местоположение. English-speaking jobs не заявляется без подтверждённого требования языка |
| По работодателю | מכבי דרושים נתניה и сочетания реального работодателя + роль + город | Только корректно обозначенный работодатель/источник; без заявления о партнёрстве |

Первая цель — полезные конкретные страницы под существующий фонд, затем расширение под спрос и реальные вакансии. Не создавать десятки пустых страниц городов, не копировать целиком чужие описания, не обещать работу без опыта/из дома/зарплату, если это не подтверждено. Регион Кесарии из исторического запроса — будущая цель при наличии проверенного фонда, а не утверждение сегодняшней полноты.

Порядок продолжения: отдельные индексируемые he/en URLs с reciprocal hreflang → серверные страницы действительных вакансий + ссылки из каталога → валидный JobPosting при наличии обязательных фактов и удаления закрытых вакансий → реальные регион/роль landing pages → Search Console и анализ impressions/clicks/CTR/queries → полезные материалы по реальным вопросам кандидатов. Успех измеряется органическими переходами и завершёнными откликами, а не числом вставленных слов. Гарантии первого места и сроков нет.

Источники требований Google: [SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide), [meta keywords не влияют на ranking](https://developers.google.com/search/docs/crawling-indexing/special-tags), [robots/noindex](https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag), [JobPosting](https://developers.google.com/search/docs/appearance/structured-data/job-posting), [multilingual URLs](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites), [keyword stuffing](https://developers.google.com/search/docs/essentials/spam-policies).

## Три предлагаемых FAQ — до выбора владельца

Проверки реализации: 73/73 локальных теста пройдены; TypeScript; отдельные production/preview builds. HTTP Production: главная index/follow и официальный canonical; view=admin, invite, неподтверждённая вакансия, client-portal/review noindex. Production robots/sitemap корректны; отдельный Preview build: noindex/nofollow, Disallow /, пустой sitemap. Браузер localhost: главная без niqqud, 4 FAQ без AI-вопроса, пустой companies-блок отсутствует; конкретная Nursing student vacancy открывается без niqqud в карточке, тексте и document.title. Проверены размеры 390×844 и 768×1024 без горизонтального overflow. Эти результаты локальные; SHA и отдельная проверка live после push фиксируются в Linear.

1. **איך שומרים משרה כדי לחזור אליה אחר כך?** / How can I save a job for later? — войти, нажать значок сохранения; вернуться через Saved jobs.
2. **אילו פרטים וקבצים צריך להכין להגשת מועמדות?** / What details and files should I prepare before applying? — заполнить обязательные поля формы, актуальный профиль/CV; требования зависят от реально доступной формы. Не обещать отправку без CV.
3. **איך מוצאים משרות לפי אזור וסוג תפקיד?** / How do I find jobs by area and role? — выбрать field/role/region/city и нажать Search; не обещать ещё не работающие email alerts.
