Устойчивый ключ: `pilot_source_jobs(source_system='civi-goodjob',source_id=<Civi UI record ID>)`. Номер вакансии API и код публикации не являются UI ID. Не относящиеся к поднабору вакансии не закрываются и не удаляются.

Вакансии относятся к организации «תעסוקה טובה», а client_id — к соответствующему клиенту агентства. Это внутренние агентские jobs, не external_jobs: отклики доступны разрешённым сотрудникам агентства по действующим RLS, автоматическая отправка в Civi или клиенту не добавлена.

Прямой URL: `https://www.hr-ai.tech/?job=<jobs.id>` (без source=external).

## Неизвестные условия

Миграция070 разрешает пустой work_mode для источника без сведений об офисе/гибриде/удалённой работе. Существующий интерфейс пропускает неизвестное значение; право доступа не изменяется. Нельзя автоматически назначать «в офисе» импортированному водителю или выездному технику. Существующий default сохраняется для старого редактора, явный импорт использует пустое значение. Зарплата/тип занятости не выводятся из предположений; исходный текст с опубликованными условиями сохраняется. Отсутствующая структурированная география обозначается «לא צוין במקור».
