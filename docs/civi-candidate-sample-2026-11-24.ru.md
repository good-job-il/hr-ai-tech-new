Отдельная SQLite staging-копия содержит 15 snapshots (3 authoritative CSV profiles + 12 UI sections) и 11 byte-identical file blobs. Это архив источника, не product tables/production import. Поля формы, скрытые браузером, не считаются достоверными значениями: для контактов авторитетны штатные profile CSV, не placeholder из UI snapshot.

SHA-256 всех 11 копий совпал с исходными browser downloads. PDF успешно разобран pypdf; DOCX ZIP прошёл integrity test и содержит word/document.xml; TXT непустой. Оригинальные bytes и формат сохраняются, преобразований в PDF не было. Текущий продукт PDF-only: поддержка DOCX/TXT не объявлена добавленной.

Это идемпотентность точного snapshot, а НЕ решение incremental reconciliation: устойчивые source event/referral IDs в проверенном CSV отсутствуют.

Проверка рабочего agency pool выполнена отдельным SQL READ ONLY с параметрами из локальных profile CSV, только в организации владельца: по нормализованному телефону или email sample-a — 0 совпадений, sample-b — 1, sample-c — 0.
