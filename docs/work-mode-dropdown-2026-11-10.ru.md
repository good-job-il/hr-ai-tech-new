# HR-28: компактный фильтр способа работы —10.11.2026

Прямое решение владельца: вместо вертикальной радиогруппы «אופן העבודה» использовать компактный select как соседние фильтры.

В app/jobs-catalog.tsx теперь label с нативным select и тем же управляемым mode/onChange. Сохранены порядок и значения: пустое значение/all arrangements, onsite, hybrid, remote; все HE/EN подписи без изменения. Фильтрация, порядок фильтров, reset и возврат на первую страницу не менялись. Неизвестный work_mode по-прежнему показывается только при выборе всех вариантов. Удалены неиспользуемые CSS-правила радиокнопок. Цвета, рамка, шрифт и высота45px наследуются от остальных select; внутренние inline отступы4px сохраняют полную английскую подпись в узком поле телефона.
