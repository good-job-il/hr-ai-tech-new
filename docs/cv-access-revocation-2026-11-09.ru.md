| Сценарий | Фактический результат до исправления |
|---|---|
| Рекрутер без cv.download: RPC и прямое скачивание | DENIED |
| Клиент до revoke: authenticated URL | 200, CDN MISS |
| После revoke: RPC и новый URL с nonce | DENIED |
| После revoke: тот же URL | **200, CDN HIT**, private max-age около 3588 |
| После revoke: ранее выданный signed URL | **200** |
| Новый файл с cacheControl=0, тот же URL после revoke | **200, CDN HIT** |

Это воспроизводимый ответ CDN, а не предположение о локальном браузерном кэше. Простого cacheControl=0, свежего nonce или отказа RLS недостаточно для отзыва всех ранее выданных ссылок. Артефакты без токенов: `output/cv-cloud-baseline.json`, `output/cv-cloud-zero.json`. Приватный fixture manifest исключён из Git правилом `.env*`.

## Подготовленное изменение

- `/api/cv`: POST с настоящим пользовательским Bearer JWT. Организационный документ проверяется через `candidate_document_download`; клиентский — через `client_presentation_document`; файл соискателя — через новый `candidate_cv_download`. Пользовательский JWT, не secret key, определяет право доступа.
- Только после успешного RPC отдельный серверный Storage client читает байты. Ответы и ошибки имеют no-store для браузера и CDN. Ключ, Storage URL и подписанный token клиенту не выдаются. Нет публичного fallback при отказе.
- 061 вводит restrictive SELECT policy для обоих CV buckets: пользовательским JWT разрешено только перечисление метаданных по существующим RLS, получение байтов, signing, batch signing, S3/copy запрещены. Server-only secret клиент не заменяет проверку пользовательских прав.
- Все четыре пути открытия CV — карточка фонда, клиентский портал, собственный профиль, отклик/интервью — используют новый endpoint. Предпросмотр организационного PDF тоже требует cv.download: уже полученные браузером байты можно сохранить.
- Временный blob URL освобождается при закрытии/смене документа. Повторное открытие снова проходит серверную проверку. Ранее просмотренную/скачанную человеком копию физически отозвать невозможно; это не обещается.
- Права на историю, исходные карточки и общие правила сотрудничества этим этапом не расширяются.
