# Публичное число зарегистрированных кандидатов — HR-25

Решение владельца09.11.2026: «מועמדים רשומים / Registered candidates» вместо «Active candidates». Считаются реальные кандидатские регистрации с подтверждённым email, независимо от заполнения профиля или подачи отклика. Импортированные карточки организаций, работодатели/агентства и неподтверждённые регистрации не являются этим показателем.

Миграция063 добавляет public_registered_candidate_count(): единственное число bigint, без аргументов и без выдачи auth.users/PII. Кандидат определяется существующим signup account_type=candidate, как в registered_candidate_accounts прежнего census. Soft-deleted аккаунты исключены. Тестовые аккаунты исключаются доверенным server-side raw_app_meta_data.is_test=true и зарезервированными доменами .invalid/.test/example.com/example.net/example.org, включая поддомены. Для QA с реальным почтовым доменом обязателен server-side is_test; произвольный префикс имени/адреса не считается доказательством теста. Существующие рабочие аккаунты/метаданные не переписываются. Функция SECURITY DEFINER с пустым search_path, fully-qualified auth.users; anon/authenticated получают только EXECUTE агрегата.

Landing запрашивает число независимо от каталога, без пользовательского JWT, credentials и HTTP-cache. Запрос ограничен3секундами, не блокирует вакансии. Обновление при открытии, смене состояния входа и возвращении фокуса. Настоящий0 отображается0; ошибка оставляет «—», не выдаётся за0. Другие показатели не меняются. CV061/веткаba55179 не входят в выпуск.

Проверки: SQL-сценарий подтверждения email увеличивает счётчик, аккаунт без candidate_profiles учитывается; неподтверждённый/business/deleted/server-marked QA/reserved-domain QA не учитываются. Анонимный посетитель получает только число, чтение auth.users и запрос с email-аргументом запрещены. Облачная проверка точного нового аккаунта владельца выполняется без копирования email/UUID в Git/Linear: включён один раз; исключение именно этого аккаунта уменьшает результат на1. Итоговые cloud/browser/build результаты записываются в HR-25 после проверки; локальный PASS не означает публикацию.
