## Найденная и исправленная ошибка

На Windows в текущем пути с кириллицей исходная suite дала6/7 PASS. CLI-test передавал `new URL(...).pathname` в Node. Получался путь с лишним `C:` и percent-encoded именем пользователя; вместо проверки CLI исполнялся ошибочный путь, и Node печатал stack trace.

Исправление использует штатный `fileURLToPath` из `node:url`, сохраняя сами CLI-сценарии отказа и запрет утечки подробностей. Это исправление переносимости теста, не изменение прав Supabase и не новая проверка облачной выдачи CV.

Повторная suite после исправления: **7/7 PASS**. `git diff --check` PASS. Полный build не повторялся: изменены только путь запуска в тесте и этот отчёт, runtime-код не менялся.
