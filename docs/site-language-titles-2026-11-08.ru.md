# Язык сайта и заголовок вкладки

Дата: 8 ноября 2026 года. Задача: HR-17. По прямому запросу владельца английский — язык публичного сайта по умолчанию для нового посетителя. Выбран вариант **Find Jobs**, а не Find Job или Jobs.

| Язык | Заголовок главной | Направление |
|---|---|---|
| en | Find Jobs \| hr-ai.tech | LTR |
| he | חיפוש משרות \| hr-ai.tech | RTL |

`lib/site-language.mjs` хранит разрешённые языки, fallback English, переводы title/description и правило заголовка конкретной вакансии. При открытой вакансии используется её фактическое название + ` | hr-ai.tech`; при закрытии возвращается локализованный общий title. Отсутствующий перевод вакансии не придумывается — сохраняется исходный текст.

Порядок выбора:

1. Сервер читает несекретный cookie `hh-language`; без допустимого значения использует en. HTML lang/dir, начальное состояние Home и metadata получают согласованный язык.
2. При первом запуске в браузере сохраняется совместимость с прежним localStorage `hh-language`: явное he или en имеет приоритет перед начальным языком сервера. Неизвестные значения не принимаются. Если localStorage недоступен, приложение продолжает работать с начальным языком.
3. После инициализации переключатель обновляет язык интерфейса, направление и document.title; выбор записывается в localStorage и cookie для следующих запросов. Cookie действует один год, Path=/, SameSite=Lax и Secure на HTTPS. В нём нет аккаунтов, персональных данных или ключей доступа.
4. Существующие настройки языка авторизованного аккаунта по-прежнему загружаются AccountPreferences; title следует фактическому языку интерфейса. Новое значение по умолчанию не перезаписывает сохранённые предпочтения в БД.

Использование async cookies() в корневом layout требует рендеринга по запросу. Это намеренно: язык первого HTML и metadata не должен определяться случайным общим кэшем. Для поискового робота без cookie выдаётся English. Переключение языка в браузере не является переводом AI. Добавление нового языка требует явного перевода UI и title в поддерживаемом наборе; неизвестные языки пока получают английский fallback.

Проверки: unit-тесты fallback/сохранённых предпочтений/заголовков вакансий; TypeScript и сборка; HTTP без cookie и с he/en/недопустимым cookie; браузерное переключение и reload. Для первого посещения используется отдельный локальный origin без прежних предпочтений. Облачная БД и конфигурация Auth не меняются. После push main результаты сайта www.hr-ai.tech и SHA записываются в Linear; локальные проверки не выдаются за подтверждение live-релиза.
