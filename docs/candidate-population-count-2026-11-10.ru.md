# Общий публичный фонд кандидатов — HR-25

Уточнение владельца в ночь09–10.11.2026 заменяет предыдущую метрику только регистраций: включить импортированный фонд и зарегистрированных кандидатов, каждого человека один раз, без тестовых данных. Надпись «מועמדים במאגר / Candidates in our database» не утверждает, что импортированные люди зарегистрированы на сайте или активно ищут работу.

Источники: актуальное указание владельца; project-documentation.pdf, стр.7–8; project-overview.ru.md, раздел9 «Дубликаты». Документированное правило статистики — нормализованный телефон, при отсутствии email. Имя не доказывает совпадение; глобальное слияние фондов не разрешено. Реальные карточки/контакты/даты не изменяются.

Миграция064 добавляет отдельный RPC public_candidate_population_count(): только число, без параметров, строк, организаций, имён, телефонов и email. SECURITY DEFINER с пустым search_path; публично выдан только EXECUTE агрегата, RLS и права чтения фондов не меняются.063 сохраняет прежнюю семантику для совместимости, главная переходит на064.061 и CV-ветка не входят в выпуск.

Входные данные:

- candidates незатестовых организаций, merged_into is null, все visibility: это агрегат всего фонда;
- подтверждённые, неудалённые auth.users с account_type=candidate, независимо от заполнения candidate_profiles;
- QA организации is_test, server-side raw_app_meta_data.is_test и зарезервированные test/example email-домены исключаются; карточка с email явно тестового аккаунта также исключается;
- телефон аккаунта берётся из валидного account_settings.contact_phone, затем candidate_profiles.phone, затем signup contact_phone; используется существующая валидация/нормализация, включая израильский bare5 префикс.

Счётчик делает distinct по телефону, затем email. Email-only аккаунт/карточка с единственным известным телефоном для этого email привязывается к той же phone identity, чтобы регистрация существующего человека не прибавляла дубль. Если одному email соответствуют разные телефоны, они не сливаются автоматически: сохраняется документированный приоритет телефона. Различные имена не объединяются. Это уникальность по имеющимся контактам, не гарантия установления личности при ошибочных/общих/изменившихся контактах. Строки без обоих идентификаторов не создают выдуманную личность; текущая read-only проверка нашла0таких строк.
