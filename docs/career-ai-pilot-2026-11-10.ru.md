# AI-инструменты центра карьеры — 10.11.2026

## Решение и границы

Прямое поручение владельца в HR-29 заменяет историческое исключение активного AI из пилота (PDF, стр.3): подключить четыре инструмента через OpenAI, используя доступные кредитные льготы, без дополнительных покупок и автоматического пополнения. Это не разрешение на оплату или изменение тарифного плана.

Инструменты: улучшение текста CV; консультативное сравнение опыта с требованиями введённой вакансии; подготовка вопросов и плана ответов к интервью; предложения по развитию карьеры. Они не принимают решений о найме, не ранжируют кандидатов и не создают вымышленный процент соответствия. Отправки откликов, массовой обработки фонда, чтения CV из Storage и новых интеграций нет.

## Реализация

- `POST /api/career`: серверный `auth.getUser` через Supabase, подтверждённый email, явный `consent: true`, проверка задачи, языка и размеров. Нет service-role обхода доступа.
- Пользователь сам вводит профессиональный текст. Согласие на отправку именно этого текста в OpenAI показано рядом с кнопкой; при изменении текста/инструмента/языка оно сбрасывается. Без входа или настройки вызовы недоступны. Текст не записывается в БД, браузерное хранилище или прикладные логи.
- OpenAI Responses API, `gpt-6.1-sol`, reasoning low, `store: false`, строгая JSON Schema, максимум3000 output tokens и45секунд ожидания. `store:false` не является обещанием нулевого retention у провайдера; UI сообщает об ограниченном safety retention. Нет tools, автоматических повторов или платного fallback.
- Профиль ограничен16000символами, вакансия8000, весь входящий поток100000байт. Сравнение и интервью требуют текста вакансии. Ответ проверяется; niqqud удаляется только на границе отображения через общий Hebrew helper. HTML модели не исполняется.
- В UI есть четыре инструмента HE/EN, ручной ввод, согласие, явные ошибки, summary/suggestions/limitations. Публичная метка «AI pilot» появляется только при доступной серверной конфигурации; иначе сохраняется «Coming soon».

## Секреты и контроль использования

Только серверные переменные: `OPENAI_API_KEY`, `CAREER_AI_CREDITS_ONLY=true`, `CAREER_AI_CREDITS_VALID_UNTIL=<ISO timestamp>`. Не помещать ключ в `NEXT_PUBLIC_*`, Git, Linear, снимки экрана или клиентский bundle. API key должен принадлежать отдельному проекту пилота и иметь только разрешение Responses write (с необходимым read), без административного доступа.

`CAREER_AI_CREDITS_ONLY` — подтверждение оператором проверенной настройки аккаунта, а не автоматический запрос баланса или управление оплатой. До включения оператор проверяет действующий grant, выключенный auto-reload и подходящий hard limit в OpenAI. По истечении указанного срока сервер останавливает вызовы до повторной проверки кредита. HTTP429 обрабатывается без покупки, повторного запроса или переключения провайдера. Приложение не имеет кода покупки кредитов и не меняет billing.

Ограничение расходов у провайдера может применяться с задержкой; нельзя выдавать его за математическую гарантию точной суммы. Не включать платное пополнение. Оператор не должен расширять срок доступности без проверки следующего grant.
