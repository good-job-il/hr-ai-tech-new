# Производительность публичной платформы и положение логотипа

09.11.2026, HR-20. Владелец попросил устранить медленную работу и вернуть логотип слева.

## Изменения

-16 account/org компонентов Home загружаются через next/dynamic при открытии соответствующих разделов. Каталог и детали вакансий остаются в основном пути; права, обработчики и содержимое не менялись.
- Переведённые jobs, счётчики регионов и список jobs для выбора города мемоизированы по фактическим зависимостям. Ввод роли/города не пересчитывает неизменившиеся регионы и не создаёт новый массив для LocationInput. Все4 фильтра, их порядок, значения и правила пересечения сохранены.
- landing-reference-atlas и design-reference переведены в lossless WebP. Сравнение декодированных RGBA bytes с PNG подтвердило полную идентичность. Оригиналы сохранены.
- Вместо1326103-byte brand bitmap для favicon используется5292-byte48px PNG; apple icon61897 bytes/180px. Основной логотип не изменён.
- Header использует физический LTR layout: логотип слева в обеих языковых версиях; nav/actions сохраняют свой direction. Направление hero/head-facing-card не затронуто.

## Измерения и пределы

До изменения: production HTML ссылался на13 начальных JS resources суммарно1356584 bytes (декодированный размер, не gzip transfer). Local production preview после изменения:11 resources/1133133 bytes, снижение16.5%. Это измерение объёма initial scripts, не обещание ускорения всех операций на16%.

Два atlas:2609619 →1646546 bytes, уменьшение36.9% без потерь. Favicon:1326103 →5292 bytes. Браузерный cache и HTTP compression влияют на фактическую передачу.

До изменения в одном обычном production browser run: TTFB651ms,DCL924ms,load1474ms,LCP964ms,CLS0.0039,longTasks3. REST catalogue365 строк308310 bytes:1055ms первый запрос и347/336ms последующие из рабочей среды. Это не эмуляция медленной мобильной сети и не полевые p75. Значительной задержки самого каталога в этих измерениях не подтверждено; его статусы/RLS/БД не изменялись.
